# XCodeWin iOS Starter v1

Minimal native SwiftUI iOS project for editing on Windows and building with Codemagic.

## Expected screen

- XCodeWin Starter
- Hammer icon
- Built through Codemagic
- Test button with a counter

## Build

1. Upload this project to GitHub.
2. Add the repository to Codemagic.
3. Run `iOS Starter - Unsigned IPA`.
4. Download `XCodeWinStarter.ipa` from Artifacts.

## Important

The IPA is intentionally unsigned. Sign it with SideStore, AltStore, Sideloadly,
or configure Apple signing in Codemagic before installing on a physical iPhone.
